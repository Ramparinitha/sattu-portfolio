# Sattu | Java Developer Portfolio

A responsive, dark futuristic portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — responsive styling and visual design
- `script.js` — mobile navigation and current year

## Before publishing
1. Open `index.html`.
2. Your email is already set to `satturamparinitha@gmail.com`.
3. Your LinkedIn profile is already linked.
4. Add repository/demo links to each project after confirming the repositories are public and ready.
5. Review the skills and project descriptions so they accurately reflect your current work.

## Run locally
Open `index.html` in a browser. No build tools or package installation are required.

## Publish with GitHub Pages
1. Upload these files to the root of your `sattu-portfolio` repository.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` (or your repository's default branch) and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site.
